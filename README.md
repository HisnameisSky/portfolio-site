# 澄界 ｜ Hisnameissky - Digital Portfolio

心惹かれるイラストレーションの世界と、モダンなWebテクノロジーが融合するインタラクティブなポートフォリオサイトです。

🌐 **Live Demo:** [https://hisnameissky.pages.dev/](https://hisnameissky.pages.dev/)

---

## ✨ Features (主な機能・特徴)

- **🖼️ Digital Artwork Showcase**
  - イラスト作品を高精細かつ安全に展示するギャラリースペース。
- **🛡️ Asset Protection System (Anti-AI Scraping)**
  - デジタルアセットの不正なAIスクレイピングや保存を防ぐため、コンテキストメニュー制御やドラッグガードなどを実装。
- **🔊 Interactive Sound Effects**
  - Web Audio APIを活用し、ホバーやクリック時に心地よいサウンドフィードバックを提供。
- **💻 Featured Projects**
  - 「AI Protection Pro Studio」をはじめとする、開発・制作したツールの詳細とリンクを掲載。

---

## 🛠️ Tech Stack (使用技術)

- **Framework:** Next.js (App Router, Static Export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Deployment:** Cloudflare Pages
